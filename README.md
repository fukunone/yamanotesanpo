# 山手線一周さんぽ（試作版）

山手線沿いを東京から外回りで歩いて一周するスマホ向けゲーム。iPhone の Safari で遊べます。

## あそびかた
1. 画面の左右をタップ（またはスワイプ）でレーンを移動
2. 体力は歩くだけで減る。おにぎり(+20)・水(+12)・おやつ(+7)で回復、ごみ・腐った食べ物・不良をよける
3. 30駅を通過して東京に戻ればゴール。記録は「どこまで歩けたか」と「一周タイム」

## ファイル
- `index.html` … 画面の骨組み
- `css/style.css` … 見た目
- `js/data.js` … 駅の順番・距離・街の雰囲気
- `js/game.js` … ゲーム本体（先頭の `CFG` で難しさを調整）
- `js/sound.js` … 効果音（すべて合成のオリジナル音）
- `js/records.js` … 自己ベスト保存とランキングの差し込み口（`Leaderboard`）
- `tools/build.py` … 1ファイル版 `dist/yamanote-sanpo.html` を作る

## アプリ化の予定
ふつうのWeb技術だけで作っているので、Capacitor でそのまま iPhone アプリにできます。
保存先は `Storage`、ランキングは `Leaderboard` を差し替えるだけで Game Center などにつなげられます。
